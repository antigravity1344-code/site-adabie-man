# راهنمای ساده پنل محتوا (ادمین)

با این پنل می‌توانی شعر، داستان، یادداشت و تصویر بالای صفحه را بدون دست زدن به کد اضافه یا ویرایش کنی.

## قبل از شروع (روی کامپیوتر خودت)

دو پنجرهٔ ترمینال لازم است (در Cursor یا VS Code: منوی **Terminal → New Terminal**).

**پنجره ۱ — سایت:**
```
cd C:\Users\mohammad\Desktop\akharin-projeh-site
npm run dev -- --port 5174
```

**پنجره ۲ — پنل (حتماً روشن باشد):**
```
cd C:\Users\mohammad\Desktop\akharin-projeh-site
npm run cms
```

اگر پیام «listening on port 8081» دیدی، پنل آماده است.

## باز کردن پنل

در مرورگر برو به:

http://localhost:5174/admin/index.html

اگر پنجره‌ای با عنوان **Development Settings** آمد:
- روی ضربدر (X) بزن و ببندش
- چیزی داخلش ننویس
- یک‌بار صفحه را تازه کن (F5)

## بخش‌های پنل

در سمت چپ (یا منوی مجموعه‌ها) این‌ها را می‌بینی:

| نام در پنل | چه کاری می‌کند |
|---|---|
| شعرها | شعرهای سایت |
| داستان‌ها | داستان‌ها |
| یادداشت‌ها | یادداشت‌های روزانه |
| تصاویر هیرو | عکس‌های بزرگ بالای صفحهٔ اصلی |

## اضافه کردن یک شعر (نمونه)

1. روی **شعرها** کلیک کن
2. دکمهٔ **New شعرها** / **ایجاد** را بزن
3. فیلدها را پر کن:
   - **عنوان** — اسم شعر
   - **تاریخ** — تاریخ انتشار
   - **نام شاعر** — اختیاری
   - **تصویر / صوت / ویدیو** — اختیاری
   - **متن شعر** — خود شعر
4. **Publish** یا **Save** را بزن
5. برو به http://localhost:5174/poems و ببین شعر آمده یا نه

داستان و یادداشت هم همین‌طور است؛ فقط فیلدها کمی فرق می‌کنند.

## ویرایش یا حذف

1. همان بخش را باز کن (مثلاً شعرها)
2. روی آیتم مورد نظر کلیک کن
3. متن را عوض کن و ذخیره کن
4. برای حذف، گزینهٔ Delete / حذف را بزن (اگر دیدی)

## نکته‌های مهم

- بدون روشن بودن `npm run cms`، ذخیره در پنل کار نمی‌کند.
- تغییرات روی فایل‌های داخل پوشهٔ `src/content` ذخیره می‌شوند.
- آدرس درست پنل همیشه این است: `/admin/index.html` (با html).
- پیام‌های فرم «گفتگو» در پنل ادمین نیستند؛ آن‌ها در Supabase → Table Editor → `contact_messages` دیده می‌شوند.
- کامنت‌های زیر شعر/یادداشت هم در Supabase جدول `comments` هستند، نه در این پنل.

## اگر پنل باز نشد

1. مطمئن شو سایت روی پورت **5174** روشن است
2. مطمئن شو `npm run cms` روشن است
3. آدرس را دقیقاً با `index.html` باز کن
4. پنجرهٔ Development Settings را با X ببند
