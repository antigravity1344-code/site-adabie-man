# site-adabie-man — سایت شخصی و ادبی محمد قنبری

سایت شخصی و ادبی ساخته‌شده با **React + Vite** شامل شعرها، داستان‌ها و یادداشت‌های روزانه، با مدیریت محتوا از طریق **Decap CMS**.

## ✨ امکانات

- صفحه اصلی با سه بخش: یادداشت‌های روزانه، شعر تصویری، داستان‌ها
- صفحات مستقل برای شعرها، داستان‌ها و یادداشت‌ها با مسیرهای داینامیک (`/poems`، `/stories`، `/notes` و صفحه‌های جزئیات)
- فرم «ارسال اثر» (`/submit`) برای ارسال شعر/داستان و عکس توسط بازدیدکننده‌ها
- فرم تماس (`/contact`) و کامنت زیر شعر/داستان/یادداشت — هر دو روی **Supabase**
- پخش صدا (پخش‌کننده‌ی اختصاصی) و ویدیو برای شعرها و داستان‌ها
- دکمه‌های «کپی متن» و «دانلود متن» روی هر مطلب
- فونت‌های فارسی اختصاصی (وزیرمتن، شبنم، نستعلیق)
- مدیریت محتوا با **Decap CMS** در مسیر `/admin/index.html`
- طراحی راست‌به‌چپ (RTL)
- استقرار آماده روی **Netlify** (با `netlify.toml`)

## 🗂 ساختار محتوا

محتوا به‌صورت فایل‌های Markdown با **frontmatter** در پوشه `src/content` نگهداری می‌شود:

```
src/content/
├── poems/     # شعرها (نمونه: dance-of-words.md)
├── stories/   # داستان‌ها
└── notes/     # یادداشت‌های روزانه
```

هر فایل می‌تواند فیلدهایی مانند `title`، `date`، `author`/`desc`، `image`/`img` و بدنه‌ی اصلی داشته باشد. این فایل‌ها هم به‌صورت دستی و هم از پنل `/admin/index.html` قابل ویرایش‌اند.

بارگذاری محتوا از طریق `src/utils/content.js` انجام می‌شود که فایل‌های Markdown را می‌خواند، frontmatter را تحلیل می‌کند و آنها را بر اساس تاریخ مرتب می‌کند.

## 🚀 اجرای پروژه

```bash
npm install       # نصب وابستگی‌ها
npm run dev       # اجرای سرور توسعه (پیش‌فرض روی پورت 5173)
npm run build     # ساخت نسخه تولید
npm run preview   # پیش‌نمایش نسخه تولید
npm run lint      # بررسی کد با oxlint
```

## 📦 استقرار

- **Netlify:** فایل `netlify.toml` تنظیمات build و ریدایرکت‌ها (ازجمله `/admin/index.html`) را مدیریت می‌کند.
- برای استفاده از پنل مدیریت روی Netlify باید «Netlify Identity» و «Git Gateway» فعال باشد.
- **Supabase (کامنت/تماس/ارسال اثر):** یک پروژه در supabase.com بساز، فایل
  `supabase-setup.sql` را در SQL Editor اجرا کن، سپس `VITE_SUPABASE_URL` و
  `VITE_SUPABASE_ANON_KEY` را در `.env.local` (محلی) و در تنظیمات Environment
  Variables هاست (Netlify) قرار بده. جزئیات بیشتر: [docs/supabase-rls.md](docs/supabase-rls.md)

## وضعیت و بررسی (۸ نوامبر ۲۰۲۶)

- **نسخهٔ بررسی‌شده:** `main` روی `2f15653`، بدون تغییر ثبت‌نشده.
- **نتیجهٔ بررسی:** `npm run lint` بدون خطا؛ `npm run build` موفق (حدود ۴ ثانیه) با هشدار حجم: یکی از بسته‌ها بزرگ‌تر از ۵۰۰ کیلوبایت است و برای سرعت بهتر می‌توان کد را تقسیم کرد (انجام نشده). آزمون خودکار ندارد.
- **امنیت وابستگی‌ها** (`npm audit`): نسخهٔ منتشرشده ۰ مورد. ابزارهای توسعه ۱۱ مورد (۳ بحرانی، ۶ بالا، ۲ متوسط)، مثل `decap-server` و `vite`؛ روی سایت منتشرشده اثر ندارند ولی هنگام کار روی رایانه مهم‌اند. ارتقا انجام نشد، چون ممکن است نسخهٔ اصلی عوض شود.
- **Supabase:** حفاظت سطر (RLS) فعال است و کلید مخفی در مخزن نیست. بازدیدکننده فقط می‌تواند نظر، پیام تماس و اثر ثبت کند. محافظ هرزنامه برای این ثبت‌ها بررسی نشده.
- **اجرای محلی:** بدون فایل `.env.local` سایت بالا می‌آید ولی نظرات، فرم تماس و ارسال اثر کار نمی‌کنند. `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را مالک باید بدهد (در مخزن ثبت نمی‌شوند).
- **آزمون روی گوشی** (نیازی به نصب نیست): رایانه و گوشی به یک وای‌فای وصل باشند و VPN رایانه خاموش باشد. دستور `npm run dev -- --host` سایت را روی شبکه باز می‌کند؛ در گوشی `http://<IP-رایانه>:5173` را باز کنید. این مسیر هنوز روی گوشی واقعی آزموده نشده است.
- **اصلاح مسیر گفتگو و رسانه:** `/contact` دیگر به فوتر اسکرول نمی‌شود؛ جای‌نگهدارهای خراب «از روی سنگ‌ها» حذف شد و ویدیوی «لبیلیبل» به لینک embed آپارات رفت.
- **اسکریپت Supabase:** `supabase-setup.sql` اجرا شده؛ جدول‌ها، باکت‌ها و سیاست‌ها ساخته شده‌اند.
- **کلاینت و نظر و پنل:** بدون کلید Supabase صفحه سفید نمی‌شود؛ خطای نظر از پیام خالی جدا شد؛ شمارندهٔ یادداشت بعد از ثبت زیاد می‌شود؛ Decap روی نسخهٔ ۳.۱۷.۳ قفل شد.
- **ارسال، تاریخ و مسیر:** اگر مرحلهٔ بعدی ارسال شکست بخورد فایل آپلودشده پاک می‌شود؛ تاریخِ بدون ساعت، ساعت نشان نمی‌دهد؛ مسیر ناشناس پیام «صفحه یافت نشد» دارد؛ تصویر هیرو و پخش با صفحه‌کلید کار می‌کنند.
- **سقف نرخ:** در `supabase-setup.sql` برای نظر، تماس و اثر بر اساس IP اضافه شده؛ این بخش هنوز باید جدا در Supabase اجرا شود.
